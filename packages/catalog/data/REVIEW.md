# Requirements to check by hand

All badges were checked by hand on 2026-10-11, and the list was compared with Scouting America's 2026 merit badge list.

2026 catalog changes applied:
- **Indian Lore** is now **American Indian Culture** (renamed with the 2025 update; same requirements).
- **Citizenship in Society** was discontinued February 27, 2026. Its file stays, marked `discontinued`, for scouts finishing records; it is no longer Eagle-required.
- The **Military Service & Veterans** badge is a Test Lab pilot, not a merit badge yet, so it isn't in the catalog.
